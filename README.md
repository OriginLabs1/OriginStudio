# Origin Studio

**One workspace. One coherent ecosystem. Replaceable implementations. User-controlled execution. Reproducible knowledge. Verifiable outcomes.**

Made with love from OneOrigin.

## About

Origin Studio is OneOrigin's flagship development workspace: an Android-first, device-agnostic-by-design environment that unifies and strategically extends useful capabilities from CodeOnTheGo and TermFold while establishing reusable foundations for future OneOrigin products.

## Features

- **Real Linux Environment** - A full Debian environment inside the app
- **Native Code Editing** - Built-in file browser and editor with syntax highlighting
- **Integrated Terminal** - Full Linux terminal with PRoot support
- **AI Agent Support** - Native chat with ACP agents (Claude, Codex, OpenCode, and more)
- **Browser for Testing** - Built-in browser for dev servers and web pages
- **Project Management** - Open, create, and manage projects seamlessly

## Requirements

- Android 9+ (API 28+ recommended for full functionality)
- 4 GB RAM or more (optimized for modest hardware)
- ~2 GB free storage for Debian environment

## Building

This is an Android application built with Kotlin and Jetpack Compose. See the build.gradle files for details.
