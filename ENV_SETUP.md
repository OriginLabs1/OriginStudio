# Environment Setup

## Requirements
- JDK 21 (Code on the Go ships with JDK 21)
- Android SDK with compileSdk 36
- Android Gradle Plugin 8.13.0 (compatible with AGP 7.3.0 - 9.3.1 range)
- Gradle 8.14.3 (via wrapper)
- Kotlin 2.3.21

## Notes
- minSdk: 26 (Android 8+ compatible, blueprint recommends Android 9+)
- targetSdk: 28 (pinned for PRoot/Linux environment compatibility)
- Java source/target: 21
