How do I start a host?

On any machine with Node 20 or newer:

npx github:OriginLabs1/OriginStudio serve --root ~/origin

Or from a checkout of the repository:

node cli/origin.mjs serve --root ~/origin

The host binds to 127.0.0.1 by default. Put it behind your own TLS terminator before exposing it to a network. The token stays in this browser.
