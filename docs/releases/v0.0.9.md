# v0.0.9 — Universal, lightweight, lovable

This line makes Origin Studio reachable from anywhere and light enough to install without
thinking twice. The Android app is still the centre; the universal layer around it is new.

## Lighter

- **The bundled QVAC local-AI runtime is gone.** It added roughly 177 MB of arm64 native
  payload and could only run on API 29+ arm64 devices. The signed release APK is now 62 MB,
  down from 241 MB in v0.0.3, so it installs faster and starts faster on modest hardware.
- Local AI is deferred, not claimed. ADR-0010 records the reversal; the `LocalAiEngine`
  boundary and the availability policy will return when the Ask/Explain/Fix surface ships.
- The release pipeline no longer downloads or caches a 141 MB Maven repository.

## Universal

- **Origin Companion** — a zero-build PWA (plain HTML/CSS/JS) that lists workspaces,
  verifies history, creates checkpoints and runs health checks. Served by the host, usable
  as a static site, installable to a home screen.
- **`origin` CLI** — dependency-free Node 20+ commands: `init`, `verify`, `list`,
  `checkpoint`, `serve`, `doctor`. It imports the reference host's verification code, so a
  workspace made in the CLI opens unchanged in the app.
- **Host protocol additions** — `list_workspaces` and `list_events`, plus CORS preflight
  and `authRequired` in `/health`. Additive to `origin.host/v1`.
- **Release artifacts** — companion zip, CLI tarball and a CycloneDX SBOM ship beside the
  signed APK, all listed in `SHA256SUMS` and `release-manifest.json`.

## Lovable

- **Fleet tab** — every session on the device, grouped by project, with honest live state
  (working, running, idle) and one-tap open. Projects organise work; the fleet observes it.
- **First-run welcome** — one short screen that says what the workspace is, that it is
  local, and that the same workspace travels with the companion. It appears once, after
  provisioning, and never again.
- **No account, no tour, no telemetry.** The welcome is the only onboarding.

## Install

1. Download `OriginStudio-0.0.9.apk` and open it.
2. Or add `github.com/OriginLabs1/OriginStudio` to Obtainium.
3. For another screen: unzip `OriginCompanion-0.0.9.zip`, or run
   `npx github:OriginLabs1/OriginStudio serve`.

See [`../universal.md`](../universal.md) for the full workflow.

## Requirements

- Android 8.0+ (API 26+), arm64-v8a or x86_64.
- 4 GB RAM recommended; several GB free for Debian and developer tools.
- Internet once on first launch to unpack Debian and fetch developer tools.
